# re.je landing page

Single-page static site for [re.je](https://re.je): plain HTML and CSS, no build step, no dependencies. Fonts (Lato 400/900, latin subset) are self-hosted in `fonts/`.

Deploys via GitHub Pages: push to `main` and it goes live at https://re.je (custom domain set in `CNAME`).

The site is held to WCAG 2.2 AA and 100% Lighthouse scores in all categories; check both before pushing changes.
